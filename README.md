# UNEcon Rating

Приложение для просмотра и сравнения успеваемости студентов Санкт-Петербургского государственного экономического университета. Данные рейтинга загружаются с сайта рейтинга и сохраняются в Neo4j; интерфейс приложения построен на Streamlit.

## Возможности

- сравнение двух студентов по семестрам и предметам;
- сравнение двух учебных групп по средним баллам и оценкам;
- просмотр результатов по семестрам и общим предметам;

## Требования

- [Git](https://git-scm.com/);
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) с работающим Docker Compose.

Python и виртуальное окружение на компьютере для обычного запуска не требуются: приложение запускается в контейнерах.

## Запуск проекта

### 1. Клонировать репозиторий

```powershell
git clone https://github.com/shany000/unecon-rating.git
cd unecon-rating
```

### 2. Создать файл окружения

В Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Открой `.env` и проверь параметры подключения к Neo4j. Укажи надёжный пароль и используй те же значения при дальнейшей работе с базой:

```dotenv
NEO4J_USER=neo4j
NEO4J_PASSWORD=замени_на_надёжный_пароль
NEO4J_DATABASE=neo4j
```

Для Linux/macOS файл можно создать командой `cp .env.example .env`.

### 3. Проверить конфигурацию и запустить приложение

Из корневой папки проекта выполни:

```powershell
docker compose config -q
docker compose up --build -d
```

При первом запуске Docker скачает необходимые образы и соберёт приложение. Сервис `catalog` загрузит начальный каталог в Neo4j и после успешного завершения остановится. Статус `Exited (0)` у `catalog` является ожидаемым; сервисы `neo4j` и `visualizer` должны продолжать работать.

Проверить состояние контейнеров:

```powershell
docker compose ps -a
```

## Где открыть приложение и базу данных

После запуска доступны следующие адреса на локальном компьютере:

| Сервис | Адрес | Для чего нужен |
|---|---|---|
| Веб-приложение (Streamlit) | [http://localhost:8501](http://localhost:8501) | Главная страница, сравнение студентов и групп |
| Neo4j Browser | [http://localhost:7474](http://localhost:7474) | Просмотр графовой базы и выполнение Cypher-запросов |
| Bolt для клиентов Neo4j | `bolt://localhost:7687` | Подключение внешних инструментов к базе данных |

Для входа в Neo4j Browser используй пользователя, пароль и имя базы из `.env`. В настройках подключения Neo4j Browser укажи URI `bolt://localhost:7687`, если он запрашивается интерфейсом.

### Примеры запросов в Neo4j Browser

Количество узлов каждого типа:

```cypher
MATCH (n)
UNWIND labels(n) AS label
RETURN label, count(*) AS count
ORDER BY label;
```

Пример просмотра фрагмента графа «год → направление → группа → студент»:

```cypher
MATCH p = (:Year)-[:HAS_DIRECTION]->(:Direction)-[:HAS_GROUP]->(:Group)-[:HAS_STUDENT]->(:Student)
RETURN p
LIMIT 100;
```

В Neo4j Browser запросы выполняются в редакторе запросов. Для просмотра графа выбери визуализацию результата в виде графа, если она не выбрана автоматически.

## Полезные команды Docker Compose

Посмотреть состояние контейнеров:

```powershell
docker compose ps -a
```

Посмотреть логи всех сервисов:

```powershell
docker compose logs --tail=100
```

Следить за логами веб-приложения:

```powershell
docker compose logs -f visualizer
```

Пересобрать образы и пересоздать контейнеры после изменения кода:

```powershell
docker compose down --remove-orphans
docker compose up --build -d --force-recreate
```

Остановить и удалить контейнеры текущего проекта:

```powershell
docker compose down
```

`docker compose down` сохраняет данные Neo4j в именованных томах. **Не добавляй `-v`, если не собираешься удалять базу данных.** Команда `docker compose down -v` удаляет также тома с данными.

## Как устроена загрузка данных

- При запуске `catalog` проверяет наличие каталога в Neo4j и загружает его, если он отсутствует или заполнен не полностью.
- Списки групп загружаются по мере обращения к соответствующему году и направлению.
- При сравнении студентов и групп приложение получает необходимые карточки и рассчитывает показатели для отображения.

Первичная загрузка зависит от доступности сайта рейтинга и сетевого соединения. Если приложение ещё загружается, сначала проверь состояние контейнеров и логи.

## Устранение неполадок

**Не открывается сайт на `localhost:8501`.** Проверь `docker compose ps -a`, затем `docker compose logs --tail=100 visualizer`.

**Ошибка `port is already allocated`.** Другой контейнер или приложение использует порт `7474`, `7687` или `8501`. Проверь занятые порты командой `docker ps` и останови только тот контейнер, который больше не нужен.

**`catalog` завершился с кодом `0`.** Это нормальное поведение после успешной загрузки каталога. Если интерфейс не работает, проверь состояние `visualizer` и `neo4j`.

**Не получается подключиться к Neo4j.** Проверь, что контейнер `neo4j` имеет статус `healthy`, а значения `NEO4J_USER`, `NEO4J_PASSWORD` и `NEO4J_DATABASE` в `.env` соответствуют настройкам подключения.
